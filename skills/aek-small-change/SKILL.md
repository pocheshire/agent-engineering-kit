Resolve the current project's .aek/ENTRY.md within the allowed scope. Follow it
to the pinned ENTRY and read the pinned contract's Authority and trust section
and applicable project rules before product sources. Use the "Direct work and small change"
route in the pinned ROUTES. Confirm the scope and impact fit the route before editing.

Confirm the route fits the request and scoped rules before writing.
If AEK is absent, point to the setup skill for an authorized connection. If the
pin is damaged or unavailable, report the exact dependency and point to AEK
recovery. If access is required, follow the project's entry rules.
An intact older pin governs any route it supports. If it lacks the requested
procedure, state the available route and the upgrade needed. Keep the existing
pin until the user authorizes a separate change.
