# Agent Engineering Kit — start here

Read [the agent entry](skills/agent-engineering-kit/core/ENTRY.md), then follow it.
That is the canonical setup workflow; the skill and plugins use the same files.

Use the user's words and existing context to identify the goal. Locate the target
from the explicit path or current project; this KIT checkout is not automatically
the target. Choose Initialize for a new project, Adopt for an existing project,
Audit for a read-only conformance review, or Upgrade for an installed project.
Ask only for a missing target, a material product choice, or missing authority.
Continue ordinary technical investigation within the existing permission.
Validate installed files and real project behavior separately. Installation grants
no product implementation, deployment, or publication permission.

If the user supplied only this KIT and no goal, start a short conversation:
“What project should we prepare: a new one, or an existing project?”
Do not run an installer until the target and intent are known.
Attaching an archive alone cannot guarantee activation; the host must open this file.
