# Provenance and publication boundary

AEK's code, tests and English instructions were independently authored for this
repository. No third-party runtime code or packages are bundled. The owner chose
MIT for this implementation. The MIT license text is the standard license notice.

Private multi-project workflow research informed the requirements. Technical
access did not establish publication rights: source text, product contracts,
design tokens, targets, evidence, fixtures, permissions and machine paths were
excluded. AEK implements general engineering concepts independently. The private
research corpus is neither a dependency nor a public evidence artifact.

Official platform documentation is linked in docs/platforms.md to establish
integration formats; it is not copied into the runtime. Future third-party code
must have verified provenance, compatible terms and retained required notices.
Public release checks scan the complete publication file set and Git history;
a heuristic scanner supplements human review and is not a proof of absence.
